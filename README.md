# 🎮 坦克大战 (Tank Battle)

一个用纯 HTML5 Canvas + JavaScript 实现的经典坦克大战游戏。

## 🕹️ 玩法

- **移动**：方向键 `↑↓←→` 或 `WASD`
- **射击**：`空格键` 或 `J`
- 消灭所有敌方红色坦克即可过关，每关敌人数量和速度都会增加

## 🎯 游戏特性

- 🧱 **可破坏砖墙** — 射击可摧毁
- 🛡️ **钢铁障碍** — 不可摧毁，阻挡子弹
- 💥 **爆炸粒子效果** — 击中坦克和墙壁时有绚丽的爆炸动画
- 🏆 **关卡系统** — 3个精心设计的地图，难度递增
- ❤️ **3条生命** — 被击中后短暂无敌并重生
- 🤖 **AI敌人** — 随机巡逻 + 瞄准玩家射击
- 🎨 **坦克绘制** — 履带、炮塔、炮管等细节

## 🚀 运行方式

直接在浏览器中打开 `index.html` 即可开始游戏。

```bash
# 或使用任意 HTTP 服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```
